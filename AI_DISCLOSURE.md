# AI Disclosure

Every module below was written or substantially shaped by AI (Antigravity / Claude / Gemini). Listed as: path, what it does.

- `app/__init__.py` — Package init.
- `app/parsers.py` — Line numbering for source files, byte-identical to tools/number_lines.py.
- `app/db.py` — SQLite schema, connection management, demo case loader, CRUD helpers.
- `app/access.py` — Central access control: `visible(item_labels, persona)` is the only authority.
- `app/repo.py` — Persona-filtered repository queries; every read goes through access.visible.
- `app/verify.py` — Citation validation, basis assignment, supersession, conflict detection, deterministic gaps.
- `app/review.py` — Claim identity hashing, sticky decision matching (exact + Jaccard), version snapshots, demo seeding.
- `app/kernel_demo.py` — Trust kernel verification runner (no-model demo check).
- `app/llm/base.py` — Provider protocol definition for structured JSON generation.
- `app/llm/gemini.py` — Primary LLM provider using google-genai with JSON schema output and 45s timeout.
- `app/llm/openai_compat.py` — Fallback LLM provider for any OpenAI-compatible API with 45s timeout.
- `app/extract.py` — Line partitioning by label set, Pydantic validation, retry/fallback, demo_cache management.
- `app/eval.py` — Accuracy and benchmark evaluation against data/answer_key.json.
- `scripts/build_cache.py` — Tool to run live extraction per label set and generate demo_cache/*.json.
- `tests/make_fixtures.py` — Generates model output fixtures from data/answer_key.json with three deliberate defects.
- `tests/test_parsers.py` — Tests 1 & 2: numbering equivalence and anchor resolution.
- `tests/test_verify.py` — Tests 3 & 4: fabricated cite, cross-label cite, supersession, conflict detection, deterministic gaps.
- `tests/test_access.py` — Test 5: access.visible truth table for all personas and label sets.
- `tests/test_review.py` — Tests 6 & 7: sticky decisions, Jaccard matching, cross-label conflict visibility.
- `tests/test_model_layer.py` — Tests for schema validation retry, provider fallback, zero-network cache_only, and eval execution.
- `app/middleware.py` — WireCheckMiddleware enforcing fail-closed scanning for canary strings on HTML responses and injecting wire audit strip.
- `app/main.py` — FastAPI application routes for home, role switching, demo open/reset, sources, claims, drawer partials, and tab stubs.
- `static/baton.js` — Vanilla JS keyboard navigation (J/K/A/E/R/Enter) under 60 lines for Approver persona.
- `templates/base.html` — Base layout shell: skip link, top bar with SVG wordmark and persona radiogroup, tabs, and wire strip.
- `templates/_macros.html` — Jinja macros for claim, cite, tag, status, redacted_claim, srcline, and wire.
- `templates/home.html` — Home landing page with one-click demo launcher per DESIGN.md section 5.
- `templates/claims.html` — Claims ledger view with filter pills, status badges, server-drawn redaction stubs, and source drawer.
- `templates/sources.html` — Sources listing with upload form for Approver and responsive table.
- `templates/drawer.html` — Source drawer partial rendering cited file lines and highlighting target line.
- `templates/gaps.html` — Gap interview screen with answer form, clearance-constrained label selector, and attestation cards.
- `templates/conflicts.html` — Disagreements view with side-by-side claim comparison and clearance notices.
- `templates/timeline.html` — Chronological timeline with dates, vertical rails, and superseded claim styling.
- `templates/handover.html` — Handover document view in Newsreader serif with SPEC section 8 ordering, successor label stripping, and redaction stubs.
- `templates/approvals.html` — Snapshot history of approved handover versions, claim counts, seeded flag, and receipt status.
- `app/leaktest.py` — Automated leak test runner across all roles and views, verifying zero canary leaks, stub markup, successor label exclusion, and positive controls.
- `templates/trust.html` — Trust page displaying 96px mono leak counter, accuracy measures from eval, honesty lines, and test trigger buttons.
- `scripts/capture_screenshots.py` — Playwright script to capture full-page audit screenshots at 1440w and 390w.
- `tests/test_tab_counts.py` — Test: persona-filtered tab counts equal openable rows for every persona.
- `tests/test_drawer_centering.py` — Playwright test asserting drawer opens on ?open_cite=, gives srcline--cited, and centers line vertically.
- `tests/test_screens_flows.py` — Integration test suite covering gaps answering, 404 security checks, sticky decisions, handover label stripping, and demo reset.
- `tests/test_leak.py` — Tests for leak detection: zero leaks on clean state, canary injection catching, and positive controls.
- `tests/test_core_loop.py` — Playwright end-to-end test verifying the full stranger demo loop from home page to closed handover.
- `requirements.txt` — Pinned dependency versions.
- `app/auth.py` — Principal dataclass and demo_principal role mapping for authorization.
